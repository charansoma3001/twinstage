# MediaPipe Hand Landmarker

- `hand_landmarker.task`: the Hand Landmarker model from Google's MediaPipe.
- `vision_wasm_internal.{js,wasm}`: the WebAssembly runtime from
  `@mediapipe/tasks-vision`.

Bundled locally so hand tracking works offline at demos.
